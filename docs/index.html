見直しの流れ

いくら払っているかを並べた後の、次の一手までを1つのアプリで進めます。

  1. 答える

    マイサブスクのカードで、使った回数を押して答えます

  2. 提案

    他のプランや解約が、差額付きで一覧表示されます

  3. 解約ページ

    加入経路を答えると、解約・変更のページが開きます

  4. 記録

    先月との差額と、調整の履歴が残ります
