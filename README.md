# セツサブ

サブスクの出費を見直す iOS アプリ「セツサブ」の、問い合わせ・要望・不具合の受付です。
このリポジトリには、アプリのコードは入っていません。

## 送り方

[新しい Issue を作る](../../issues/new/choose) から、種類を選んで書いてください。

- **不具合**：どの画面で、何を押したら、どうなったか
- **要望**：こうなると助かる、という使い方
- **値段のまちがい**：サービス名・プラン・正しい値段・確かめたページ

## 書かないでほしい物

Issue は、誰でも読めます。次の物は、書かないでください。

- 氏名・住所・電話番号・メールアドレス
- カード番号、アカウントの ID やパスワード
- 契約している全サービスの一覧（例が要る時は、サービス名だけに）

## 返事について

個人で作っているため、返事に日数がかかることがあります。
